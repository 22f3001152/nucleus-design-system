## Web Components
Browser-native component model using Custom Elements.

## Stencil
A compiler that produces standards-based web components.

## Design Tokens
Reusable design decisions (color, spacing, typography, etc.) represented as variables.

## CSS Custom Properties
Runtime-overridable CSS variables (e.g. `--nucleus-color-primary`).

## Atomic Design
Methodology to classify UI as Atoms, Molecules, and larger compositions.

## Output Targets
Stencil generators that create React and Angular wrappers.

## Compodoc
Angular documentation generator used by Angular Storybook.

## Nx
Monorepo task orchestrator with caching and dependency-aware execution.
