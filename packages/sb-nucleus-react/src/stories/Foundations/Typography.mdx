# Typography

Nucleus uses a structured typography system based on design tokens. All typography is driven by CSS custom properties, allowing for easy global or scoped overrides.

## Theming & Overriding

The design system is built to be highly customizable. If you are importing Nucleus into your React or Angular application, you can easily override the default typography by updating the CSS custom properties in your global stylesheet (e.g., `App.css`, `styles.scss`, or `index.css`).

### Global Overrides

To update fonts globally for your entire application, redefine the variables in the `:root` pseudo-class.

```css
/* App.css or global.scss */
:root {
  /* Set your primary font family */
  --nucleus-font-family-sans: 'Inter', system-ui, sans-serif;

  /* Optionally adjust the base scale */
  --nucleus-font-size-base: 18px;
  --nucleus-font-weight-bold: 900;
}
```

### Angular 18+ Integration

In an Angular 18+ project, you can apply these overrides in your global `styles.scss` or within specific standalone component styles. Because CSS custom properties cross Angular's view encapsulation boundaries, they are a powerful way to theme external component libraries.

#### Global Override (src/styles.scss)

```scss
/* src/styles.scss */
:root {
  --nucleus-font-family-sans: 'Outfit', sans-serif;
  --nucleus-font-size-base: 1.1rem;
}
```

#### Component-Level Override (example.component.scss)

If you only want a specific component to use a different typography, apply the variable to the `:host` selector.

```scss
/* src/app/dashboard/dashboard.component.scss */
:host {
  /* Only overrides values for this component and its children */
  --nucleus-font-family-sans: 'Inter', sans-serif;
  --nucleus-font-weight-medium: 600;
}
```
